Integration evidence:

1. Missing HMAC returned 401 and wrote no ledger; unauthenticated ledger retrieval returned 401.
2. Exact event replay returned cached text; the same event ID with modified input returned 409 and wrote nothing.
3. A signed PIN/farm/season/category/amount/date/review flow followed by ten concurrent confirmations produced one ledger entry, one event and one receipt UUID. The owner retrieved the same amount through the authenticated ledger endpoint.
4. Three wrong PIN attempts closed the session and activated the global credential lock without creating another expense.
5. Phone/session mismatch created a durable metadata-only security event. Changing the PIN credential version after review caused confirmation to fail closed without a new expense.
6. Cancelled and database-expired sessions produced terminal responses and no expense. Direct ledger updates and event deletes were rejected by append-only database triggers.
7. The Farmer-JWT-protected demo endpoint rejected an anonymous request, then processed a full PIN/farm/season/category/PKR 321/date/review/confirm session through the same state machine. The returned receipt UUID and `32100` paisa amount were retrieved from the authenticated ledger.
